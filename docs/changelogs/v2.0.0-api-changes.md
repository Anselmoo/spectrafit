# v2.0.0 API Changes

This page summarizes the main API-facing changes in the v2 migration.

## Canonical contracts

- `spectrafit.core.fitting_config.UnifiedFittingConfig` is the single validated
  input contract for runtime fitting.
- `spectrafit.models.fit_result.FitResult` is the canonical runtime and persisted
  result contract.

## Interface shifts

- The CLI is subcommand-based (`fit`, `validate`, `convert`, `report`, `init`,
  `new-config`, `plugins`, `jupyter`).
- Jupyter is exposed as a first-class interface instead of a bundled plugin
  command.
- The external plugin system uses `spectrafit.plugins` entry points for
  third-party extensions.

## Compatibility posture

- Legacy v1 input shapes are progressively quarantined behind explicit adapters
  and migration helpers.
- Frozen legacy packages remain for compatibility, but they are not the canonical
  owner for new runtime behavior.
