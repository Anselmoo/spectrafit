# v2.0.0 Breaking Changes

!!! warning "Major Version Update"

    **SpectraFit v2.0.0** contains breaking changes that remove several modules
    and features. Please review this document carefully before upgrading.
    See the [migration guide](../interface/migration-v2.md) for step-by-step
    upgrade instructions.

---

## Removed Features

### :magnet: Mössbauer Spectroscopy

All Mössbauer spectroscopy support has been removed (~3,000 lines across 27
files).

| Removed Module | Description |
|---|---|
| `spectrafit.models.moessbauer` | Singlet, doublet, sextet, and octet models |
| `spectrafit.api.moessbauer_model` | Mössbauer API model definitions |
| `spectrafit.api.model_utils` | Utility functions (Mössbauer-only) |
| `spectrafit.api.physical_constants` | Physical constants module |
| `spectrafit.plugins.moessbauer_plugin` | Mössbauer CLI plugin |

- CLI entry point `spectrafit-moessbauer` removed
- `pytest` marker `moessbauer` removed
- All associated test files removed

!!! info "Why?"

    Mössbauer spectroscopy was an experimental addition with limited adoption.
    Removing it reduces maintenance burden and sharpens the project scope on
    general-purpose spectral fitting.

### :ocean: RIXS Plugin

The Resonant Inelastic X-ray Scattering (RIXS) converter plugin has been fully
removed.

- `spectrafit.plugins.rixs_converter` module deleted
- RIXS CLI command removed
- All RIXS documentation removed

### :mountain: AutoPeak Detection

The automatic peak detection feature has been gutted (804 → 278 lines) and
retained as a **placeholder** for future redesign.

| Symbol | Status |
|---|---|
| `AutoPeakDetection` class | :x: Removed |
| `define_parameters_auto` method | :x: Removed |
| `detection_check` method | :x: Removed |
| `autopeak` configuration field | :x: Removed from CLI, API, and notebook interfaces |
| `ModelParameters` class | :white_check_mark: Still available |
| `ReferenceKeys` class | :white_check_mark: Still available |

!!! note "Module Retained"

    The `spectrafit.models.autopeak` module file still exists but only contains
    `ReferenceKeys` and `ModelParameters`. It serves as a placeholder for a
    future redesign of automatic peak detection.

### :file_folder: Static Examples

- `Examples/` directory deleted (43 files, ~1 MB)
- Replaced by programmatic data generation via
  `spectrafit.generators.synthetic.SyntheticSpectrum`

### :wrench: Other Removals

| Removed Item | Notes |
|---|---|
| `spectrafit.tools` module | Migrated to core modules in v1.x; stub removed |
| `spectrafit.spectrafit` simplification | Reduced from 435 → 70 lines |

## Changed Behavior

### Import Path Changes

| v1.x Import | v2.0.0 Status |
|---|---|
| `from spectrafit.models.moessbauer import ...` | :x: Removed |
| `from spectrafit.models.autopeak import AutoPeakDetection` | :x: Removed |
| `from spectrafit.models.autopeak import ModelParameters` | :white_check_mark: Still available |
| `from spectrafit.plugins.moessbauer_plugin import ...` | :x: Removed |
| `from spectrafit.plugins.rixs_converter import ...` | :x: Removed |
| `from spectrafit.tools import ...` | :x: Removed |
| `from spectrafit.generators.synthetic import SyntheticSpectrum` | :sparkles: New |

### Configuration Changes

!!! danger "Configuration Incompatibilities"

    The following configuration fields are **no longer accepted** and will raise
    errors if present in your JSON, YAML, or TOML input files.

- `autopeak` field no longer accepted in fitting configuration
- Mössbauer model types (e.g., `moesbauer_singlet`, `moesbauer_doublet`,
  `moesbauer_sextet`, `moesbauer_octet`) are no longer valid in `peaks`
  configuration

## New Features

### :sparkles: Synthetic Data Generator

A new module for reproducible test data generation:

```python
from spectrafit.generators.synthetic import SyntheticSpectrum
```

- `SyntheticSpectrum` — Pydantic model with noise injection and ground-truth
  tracking
- `PeakDefinition` — Structured peak parameter definitions
- Supports programmatic generation of test spectra, replacing the static
  `Examples/` directory
